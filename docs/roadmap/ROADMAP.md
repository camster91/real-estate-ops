# Roadmap

## M0 — Product Definition
Workflows, service taxonomy, roles, permissions, data model, integrations, compliance matrix, UX map.

## M1 — Platform Foundation
Monorepo, CI, environments, auth, tenancy, RBAC, database, audit, transactional outbox, shared action-level/approval primitives, storage, observability.

## M2 — CRM + Leads
Parties, relationships, contact timeline, leads, assignment, qualification, consent, funnel.

## M3 — Properties + Listings
Property/unit model, ownership, listings, external references, property timeline.

## M4 — Transactions + Work
Transaction templates, stages, workflows, tasks, dependencies, approvals, calendar deadlines.

## M5 — Documents + Compliance
Document requirements, SkySlope foundation, FINTRAC records/status, trade record sheets, trust reconciliation support.

## M6 — Communications
Gmail/M365 and calendar integration, conversation association, drafts, notifications.

## M7 — Mac Agent Gateway
Device registration, heartbeat, job execution, Hermes/Codex adapters, approvals, logs, offline handling.

## M8 — Automation + Ops Inbox
Domain event consumers on the M1 outbox, deterministic rules, risk/exception inbox, AI summaries/recommendations.

## M9 — Finance + Reporting
Commission model, referral fees, operational finance references, owner/manager/agent/BOR dashboards.

## M10 — Pilot
Synthetic test, sandbox users, migration dry-runs, limited live transaction pilot, feedback.

## M11 — Production
Security review, restore test, performance, incident runbooks, training, staged rollout and rollback.
